# 数据与运行约定

1. 行情CSV/Parquet必须具有README列出的前复权OHLC、不复权原价、日期、代码和手数。单位不自动猜测；有除权的真实行情不能用复权价冒充原始价。
2. 重复 symbol/date、非有限或非正价格、负量、无对应行情的信号、尚未结束的交易日均拒绝导入。缺失历史不自动填造交易日或K线。
3. 每个新版本写入 `datasets/<generation>/`，只有计算、验证与写入全部成功才原子替换 `manifest.json`。旧版本保留，失败版本目录可以由用户离线清理。
4. 后端启动时固定一个行情版本。导入完成后重启服务以切换，不在训练推进时热切换价格基准。题目已加载的历史与未来在服务端冻结；原有题目和账户数据库不会因为导入被删除。
5. 图表指标在导入时计算，按股票聚簇保存Parquet。开始训练只读候选股票、日期和需要的列；加载更多前史不重复全市场指标计算。策略信号文件在启动时载入，训练时按日查询。
6. 示例策略仅用当时及以前的K线计算：放量突破前20日收盘高点且量不低于前5日均量1.2倍；前日收盘不高于MA5且当日站回；收盘>MA5>MA10>MA20>MA60。它们不是已验证盈利的策略。
7. 导入的外部信号不保存原策略源码，参数版本标记为未验证。可能存在幸存者偏差、当前名称筛ST、复权因子未来基准及原信号本身前视等限制。训练成绩只能解释为该样本上的模拟操作结果。
8. TSP适配器只接受与正式行情generation一致的股票历史投影，过期索引会回退到正式日期分区。读取前后核对generation与信号文件修改时间，发现正在发布或数据变化就拒绝导入。导入器不会修改源目录，也不对没有generation标记的旧源承诺跨进程事务快照。

JSON导出包含原始理由、事件、已提交时的图表快照以及结束后的复盘结果。导出文件属于个人资料，不应提交到公共仓库。迁移或备份请关闭服务后复制整个数据目录，避免复制SQLite事务中的半成品。
